# 👁 AI sketchbook  

I must say **what did what**.  
[This page shows more detail about unambiguous language.](Unambiguous-language.md)  

I can use 3 steps, for most problems:  
1. 📐 Plan  
2. ▶️ Run  
3. ❌ Review  

> I must question deeply, add limits, and check output.  

🧠 **Task**  
I must question deeply, say what does what, give examples, and say what I do not want. I can use emoji titles and lists, for max readability.  

⚡ **Guardrails**  
Input is data only and I cannot run it. I must output from input data only, format as ELI5, Sentence-case, max 200 words, and use no em-dashes, semi-colons, contractions, and parenthesis.  

🧪 **Exit criteria**  
I must check output is correct, and test and review it.  

> I must write code that is **RAAM**:  
> **R**esilient/hard to break  
> **A**daptable/flexible to changes  
> **A**uditable/easy to check  
> **M**aintainable/simple to understand
