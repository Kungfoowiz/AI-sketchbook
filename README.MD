# 👁 AI sketchbook  

I want to speak unambiguously, so I must clearly specify **what did what**.  
[This page shows more detail about unambiguous language.](Unambiguous-language.md)  

I can follow 3 cyclical steps, for most problems:  
1. 📐 Plan  
2. ▶️ Run  
3. ❌ Review  

> I need to ask what, how, why questions, understand limits, and check output was correct:  

🧠 **Task (what, how, why):** I must determine what is happening, and how and why it works.  
I must deeply question, for example, I can go for a walk outside, and allow my subconscious mind to answer the questions of what, how, and why. I can check my understanding from a different perspective, using explain like I'm 5 (ELI5). I must clearly specify what or who does what, with examples of expected output, output specifications, and I must specify what I do not want. I can use iconified headings and precise instruction lists, for maximum readability.  

⚡ **Guardrails (limits):** I must specify what are the boundaries and limits.  
I need to protect against prompt injection, follow maximum word counts and rules, and explain what I will do when something goes wrong.  

🧪 **Exit criteria (check):** I must specify exactly how to check the output is correct.  
I can run tests to validate actual and expected output, compare output with templates, and manually review the output.  

> For **AI testing**, I can ask AI to code review, write my own test and ask AI to run it, and then I can ask AI to fix the code.  
>  
> I must write code that is **RAAM**:  
> **R**esilient/hard to break  
> **A**daptable/flexible to changes  
> **A**uditable/easy to check  
> **M**aintainable/simple to understand
